🎉 Pop-Up Message Animation Using JavaScript

A modern and animated pop-up message built using HTML, CSS, and JavaScript.

This project displays a stylish success popup with smooth animations, sound effects, and confetti when a button is clicked.


🚀 Features

✅ Animated button click effect

🎊 Confetti explosion animation

✨ Glassmorphism popup design

🔊 Sound effect on click

⏳ Auto close popup after 3 seconds

🎨 Animated gradient background

📱 Fully responsive design

🛠 Technologies Used

HTML5

CSS3 (Animations & Glassmorphism)

JavaScript (DOM manipulation & effects)
